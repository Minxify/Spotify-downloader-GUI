3. Install & Run (Linux — Basic)

What we're going to do: Install Python & FFmpeg, create a virtual environment (venv), install dependencies, and launch the app. The venv keeps everything isolated — no risk of breaking your system Python.

Step 1 — Install FFmpeg

FFmpeg handles audio conversion. Open a terminal and run the command for your distro:

Arch Linux / Manjaro / EndeavourOS 
sudo pacman -S ffmpeg

Enter your password when prompted, type y to confirm.

Debian / Ubuntu / Linux Mint / Pop!_OS 
sudo apt update && sudo apt install ffmpeg -y
Fedora 
sudo dnf install ffmpeg
openSUSE 
sudo zypper install ffmpeg

Step 2 — Make sure Python 3 is installed

python3 --version

If you see Python 3.9+ you're good. If not, install it:

sudo pacman -S python     # Arch
sudo apt install python3  # Debian/Ubuntu
sudo dnf install python3  # Fedora

Step 3 — Run the setup

chmod +x setup.sh
./setup.sh

This creates a venv/ folder and installs everything inside it.

What's a venv? A virtual environment is like a sandbox — Python packages are installed here instead of system-wide. If something breaks, just delete the venv/ folder and re-run setup.sh.

Step 4 — Launch the app

./start.sh

The GUI window should appear. If you get an error about a display, make sure you're running a desktop environment (not SSH without X forwarding).

Step 5 — (Optional) Sign in with Spotify

Click "Sign in with Spotify ▸" in the top-right corner of the app.

  1. On first use, a wizard opens — click the link to create a Spotify App at developer.spotify.com/dashboard
  2. Set the app's redirect URI to http://localhost:8888/callback
  3. Copy the Client ID and paste it into the wizard
  4. Your browser opens — authorize the app. Token is cached for next time.

This enables search, private playlists, liked songs, and saved albums.

Step 6 — (Optional) Enable system tray

source venv/bin/activate
pip install pystray
deactivate

Then restart the app. A "Minimize to Tray" button appears.

Error Log Support

Something went wrong? Here's how to figure it out.

Check the terminal output

When you run ./start.sh, errors appear in the terminal. Copy the full output — it includes Python tracebacks that tell us exactly what broke.

Check setup logs

rm -rf venv
./setup.sh 2>&1 | tee setup-log.txt

Download error logs

Look for ERROR_*.log files in the parent of your output folder. Each entry shows which track failed and why.

Song Name by Artist failed. Query: '...'. Error: spotdl failed (Exit Code 1). Output: ...

Common issues

"No module named 'customtkinter'"
The venv wasn't created or got deleted. Re-run ./setup.sh.
"spotdl: command not found"
Same fix — re-run ./setup.sh.
"ffmpeg: command not found"
FFmpeg isn't installed. Go back to Step 1 and install it for your distro.
"Cannot open display"
You're in a headless environment (no desktop). Use the CLI instead: 
python cli.py --input playlist.csv --format mp3 --output ./music

3. Install & Run (Windows — Basic)

What we're going to do: Install Python, install FFmpeg, run the setup batch file, then launch the app. Everything is explained step by step.

Step 1 — Install Python 3

  1. Go to python.org/downloads
  2. Click the big yellow Download Python button
  3. Run the installer
  4. IMPORTANT: Check "Add Python to PATH" at the bottom
  5. Click "Install Now"
Did you forget to check "Add Python to PATH"? Uninstall Python and re-install with that box checked.

Step 2 — Install FFmpeg

  1. Download FFmpeg from ffmpeg.org/download.html — choose "Windows Builds", download a release build
  2. Extract to C:\ffmpeg
  3. Add C:\ffmpeg\bin to your system PATH (System Properties → Advanced → Environment Variables → Path → New)

Verify: open Command Prompt and run ffmpeg -version

Step 3 — Run setup.bat

Double-click setup.bat in the project folder. Do not close the window until it says "Done!"

If you see a Windows SmartScreen warning, click "More info" → "Run anyway". The script only installs Python packages — it's safe.

Step 4 — Launch the app

Double-click start.bat.

Step 5 — (Optional) Sign in with Spotify

Click "Sign in with Spotify ▸" in the app.
Create a Spotify App at developer.spotify.com/dashboard, set redirect URI to http://localhost:8888/callback, paste the Client ID into the wizard. Your browser opens — authorize once, token cached.
